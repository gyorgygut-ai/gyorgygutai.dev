# Application Log

One row per application. Update after every interaction. Sort by status to see what's active.

---

## How To Use

1. Log every application immediately after submitting
2. Update status after every email, call, or interview
3. Set follow-up dates — never rely on memory
4. Review weekly: filter for overdue follow-ups and stalled applications
5. Archive closed applications (rejected/withdrawn/accepted) — don't delete

---

## Status Definitions

| Status | Meaning |
|---|---|
| 💾 Saved | Found the listing, haven't applied yet |
| 📤 Applied | Application submitted, waiting for response |
| 📞 Screen | Recruiter call scheduled or completed |
| 🎤 Interview | One or more interviews in progress |
| 🏁 Final Round | Last stage before offer |
| 📋 Offer | Verbal or written offer received |
| ✅ Accepted | You signed |
| ❌ Rejected | They said no |
| 👻 Ghosted | No response after 14+ days |
| 🚫 Withdrawn | You said no |

## Weekly Review Checklist

- [ ] All new applications logged (date, source, status)
- [ ] Statuses updated for any responses received
- [ ] Follow-up dates checked — send any that are due/overdue
- [ ] Interview prep notes added after every call
- [ ] Ghosted applications (14+ days, no response) marked accordingly
- [ ] Rejected/withdrawn applications archived

---

## Interview Notes Template

After every interview, jot down:

- **Date & format:** (phone / video / on-site / take-home)
- **Interviewer(s):** Name + role
- **Questions asked:** Key ones worth remembering
- **My answers:** What went well, what to improve
- **They told me:** Timeline, next steps, team info
- **Red/green flags:** Culture signals, questions they asked
- **Follow-up sent:** Yes/No + date
